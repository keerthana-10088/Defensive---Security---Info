# Defensive Security - Notes

## 1. What is Defensive Security?

Defensive security focuses on protecting systems, networks, applications, and data from cyber attacks.

The main goal is to detect, prevent, and respond to security threats.

## 2. Security Operations

Security teams continuously monitor systems and networks to identify suspicious activities.

Security operations can include:

* Monitoring security events
* Investigating suspicious activity
* Detecting attacks
* Responding to security incidents

## 3. Threat Detection

Threat detection is the process of identifying potentially malicious activity.

Security professionals look for unusual behavior, suspicious network traffic, and other indicators of compromise.

## 4. Incident Response

Incident response is the process of handling a security incident.

Common steps include:

1. Detect the incident
2. Investigate the incident
3. Contain the threat
4. Remove the threat
5. Recover affected systems
6. Review the incident

## 5. Digital Forensics

Digital forensics involves collecting and analyzing digital evidence after a security incident.

It can help investigators understand:

* What happened
* How the attack happened
* Which systems were affected
* What evidence was left behind

## 6. Security Monitoring

Security monitoring involves continuously observing systems, networks, and security logs for suspicious activity.

Monitoring helps security teams identify threats at an early stage.

## 7. Key Learning

Defensive security is important because prevention and early detection can reduce the impact of cyber attacks.
